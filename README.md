# WaWhatsApp

WaWhatsApp by Civil DigitalStore.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/68afe35935fbeab3c7b39c36/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **WaWhatsApp** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/68afe35935fbeab3c7b39c36/releases/latest) and reinstall.
